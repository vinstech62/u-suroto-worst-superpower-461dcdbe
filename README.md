raisin, anywhere on Earth, once in a lifetime — already used in 2019. A
superpower so pointless it is spent before the hero ever needs it, and the
joke lands on a single reading.

## Run it

```sh
node main.ts
```

Writes exactly one line (87 characters) to `/output/entry.txt`.
Deterministic: the same line on every run. Node 22+ standard library only,
no network, no randomness.
